`requirements.txt` и настройки `.vscode` общие для проекта.

## Запуск на Windows

Откройте весь проект в VS Code. Если окружения ещё нет, выполните в терминале:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запуск нужной работы из корня проекта:

```powershell
.\.venv\Scripts\python.exe lab1\main.py
.\.venv\Scripts\python.exe lab2\main.py
```

Для F5 выберите нужную лабораторную в разделе «Запуск и отладка».

На Linux/macOS используйте `.venv/bin/python` и пути `lab1/main.py`, `lab2/main.py`.
